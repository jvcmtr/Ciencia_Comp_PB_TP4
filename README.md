# Ciencia_Comp_PB_TP4


## Aviso importante:
Dado que o enunciado não indicou sinal verde, amarelo ou vermelho para uso de IA,
Foi tomada a liberdade por parte do aluno de usar a inteligencia artificial **SOMENTE PARA 
OS CODIGOS QUE NÃO SE RELACIONAM A COMPETENCIAS DA DISCIPLINA**. O uso da IA neste trabalho 
tem somente o objetivo de agregar ao produto final e **não de suplementar o conhecimento do 
aluno a respeito da materia**. 

Os codigos feitos com auxilio de IA estão presentes nas questões que nescessitam de
fontes de dados externas e estão devidamente apontados tanto aqui quanto como comentarios no codigo fonte:

- lista das palavras mais usadas, nescessaria na questão 2 (arquivo: `q2_word_usage.py`)
- Imagem de grafo, nescessaria na questão 3 (arquivo: `q3_maze_helper.py`)

Nota-se que nestes casos **a solução foi projetada pelo aluno** e a IA teve somente o papel de implementar o codigo. 

Nota-se também que "Feito com auxilio de IA" implica a presença de alterações do aluno 
sobre os codigos inicialmente gerados por IA (não foi realizado simplesmente Ctr+C Ctrl+V).

## Setup
\**São nescessarias bibliotecas externas para executar as questões 2 e 3.*

Instale manualmente as bibliotecas listadas em `requirements.txt` usando `pip`

**...ou siga o seguinte passo a passo:**
1. Crie um ambiente virtual
2. Ative o ambiente
3. Instale as bibliotecas

**...ou simplesmente execute**
```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
